# 📘 Teste-Versionamento

> Projeto educacional para praticar e compreender os principais conceitos de versionamento de código com **Git** e **GitHub**.

---

## 🎯 Sobre o projeto

O **Teste-Versionamento** foi criado com o objetivo de praticar e compreender os principais conceitos de versionamento de código utilizando **Git** e **GitHub**.

Durante o desenvolvimento deste projeto, são aplicadas operações essenciais do fluxo de trabalho com controle de versão, como:

- 📁 Criação de repositórios
- ✅ Realização de commits
- ⬆️ Envio de alterações (`push`)
- 🌿 Criação e gerenciamento de branches
- 🔀 Integração de alterações por meio de `merge`

## 🎓 Finalidade

Este projeto tem finalidade **exclusivamente educacional**, servindo como base para o aprendizado das boas práticas de versionamento e colaboração em projetos de desenvolvimento de software.

## 🧩 Conceitos praticados

| Conceito | Descrição |
|---|---|
| **Repositório** | Estrutura onde o histórico do projeto é versionado |
| **Commit** | Registro de uma alteração no código, com mensagem descritiva |
| **Push** | Envio dos commits locais para o repositório remoto |
| **Branch** | Linha de desenvolvimento paralela, usada para novas features ou testes |
| **Merge** | União das alterações de uma branch com outra |

## 🛠️ Comandos essenciais

```bash
# Criar um repositório local
git init

# Verificar o status das alterações
git status

# Adicionar arquivos para o próximo commit
git add .

# Criar um commit
git commit -m "descrição da alteração"

# Enviar alterações para o repositório remoto
git push origin nome-da-branch

# Criar uma nova branch
git checkout -b nome-da-nova-branch

# Alternar entre branches
git checkout nome-da-branch

# Unir alterações de uma branch na atual
git merge nome-da-branch
```
